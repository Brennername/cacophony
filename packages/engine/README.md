## Troubleshooting Guides

### Common Issues

1. **Database Connection Errors:**
   - Ensure that your database connection settings are correct in the `.env` file.
   - Verify that the database server is running and accessible.

2. **Telemetry Collection Failures:**
   - Check if there are any network issues or misconfigurations affecting telemetry data collection.
   - Review logs for any error messages related to telemetry collection.

3. **Token Analysis Errors:**
   - Ensure that the necessary permissions are set up in the database to access and analyze token usage data.
   - Verify that the collected telemetry data is stored correctly in the database.
